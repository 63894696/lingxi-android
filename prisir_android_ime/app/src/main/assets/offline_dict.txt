# 用途：**没有网络时也能翻译常用表达**（出境、进飞机、地铁、弱网）。
# 命中规则是**精确匹配**（去首尾空格）—— 不做逐词硬拼，拼出来的句子质量太差，
# 宁可明确告诉用户"离线词库没有这个词"，也不给一个似是而非的译文。
#
# 2026-11-20 精简：只保留中英互译两个语向（zh>en + en>zh），
# 其余语向（日/韩/法/德/西/俄/意/葡/越/泰/阿/繁）已删除。
#
# 格式：
#   #! src=<源语言> tgt=<目标语言>     ← 语向节头
#   <源词>\t<译文>                     ← 一条一条（同一节内键不能重复）
